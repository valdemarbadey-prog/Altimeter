# Altimeter — Wear OS

Приложение высотомера для Wear OS с отдельной плиткой.

## Возможности
- Считывает аппаратный барометр по запросу.
- Показывает высоту, Ground и расчётное MSL.
- Калибровка известной высотой и кнопками ±1 м.
- Сохраняет калибровку в SharedPreferences.
- Не запускает постоянный сервис, WorkManager или фоновый опрос.
- Плитка считывает датчик в ответ на системный запрос; периодическое обновление не задано.

## Расчёт
Высота рассчитывается относительно сохранённой пары «давление — известная высота» по приближённой формуле стандартной атмосферы. MSL — текущее давление, приведённое к уровню моря по рассчитанной высоте. Погодные изменения влияют на барометрическую высоту, поэтому для точности нужна повторная калибровка.

## Сборка
Нужны Android Studio, JDK 17 и интернет для загрузки Gradle/Android зависимостей.
1. Открой Android Studio → **Open** → выбери папку репозитория.
2. Дождись Gradle Sync. Если попросит, установи Android SDK 36.
3. Выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Если Gradle 8.13 установлен отдельно, можно собрать командой:
```bash
gradle assembleDebug
```

## Установка на часы через ADB по Wi-Fi
1. На часах открой **Settings → System → About** и несколько раз нажми **Build number**, пока не включится режим разработчика.
2. В **Settings → Developer options** включи **ADB debugging** и **Debug over Wi-Fi** (названия пунктов зависят от версии Wear OS).
3. Подключи часы и компьютер к одной Wi-Fi сети. Открой на часах экран **Wireless debugging**. Запиши IP-адрес и порт сопряжения.
4. Установи на компьютер Android SDK Platform-Tools с сайта Android Developers.
5. В терминале выполни:
```bash
adb pair IP:PAIRING_PORT
```
Введи код сопряжения, показанный часами.
6. На основном экране Wireless debugging найди IP и порт отладки, затем выполни:
```bash
adb connect IP:DEBUG_PORT
adb devices
```
7. Установи собранный APK:
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
8. Найди **Altimeter** в списке приложений на часах и открой.

## Добавление плитки
Открой карусель плиток (обычно свайп от циферблата), нажми и удерживай плитки или выбери **Add tiles / +**, найди **Altimeter** и добавь. Жесты и названия меню зависят от версии Wear OS.

## Первичная калибровка
1. Открой Altimeter и нажми «Обновить».
2. Введи известную высоту текущего места над уровнем моря в метрах.
3. Нажми «Установить высоту». В этот момент текущее давление сохраняется как опорное.
4. Используй −1 м и +1 м для тонкой корректировки. Каждая корректировка сохраняет текущие давление и высоту как новую опорную точку.

## Ограничения
- Если барометр не доступен системе, измерения невозможны.
- Wear OS сама решает, когда запрашивать содержимое плитки; нельзя гарантировать обновление ровно при каждом визуальном открытии.
- У плитки нет таймера обновления и фонового опроса.
- APK в репозитории пока не приложен. Проект необходимо собрать и проверить на самих часах.
